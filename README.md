# [Deep Hashing via Mean Centroid Representation for Large-scale Image Retrieval](https://www.sciencedirect.com/science/article/pii/S095741742602419X)
 If you have any questions, please contact 18853645805@qfnu.edu.cn.

### Start

After the dataset has been prepared, we can run the following command to train.
> python train.py

### Training

Before training, you need to download the MIRFLICKR-25K dataset from https://press.liacs.nl/mirflickr/mirdownload.html, NUS-WIDE dataset from https://opendatalab.org.cn/OpenDataLab/NUS-WIDE, and the MS COCO dataset from https://cocodataset.org/.
